# Security Policy

LedgerForge is financial infrastructure software. Please do not report suspected security vulnerabilities through public GitHub issues.

## Reporting A Vulnerability

Email security reports to:

security@ledgerforge.io

Include as much detail as possible:

- affected component or endpoint
- impact and exploitability
- reproduction steps
- relevant logs, requests, or proof-of-concept code
- suggested remediation, if known

We will acknowledge valid reports and coordinate remediation privately before public disclosure.

## Scope

Security reports are welcome for LedgerForge Core, Docker images, default deployment configuration, authentication and authorization behavior, data integrity, transaction processing, reconciliation flows, and operational surfaces exposed by this repository.

## Out Of Scope

- Denial-of-service reports that rely only on resource exhaustion without a practical exploit path
- Vulnerabilities in unsupported forks or modified deployments
- Social engineering, phishing, or physical attacks
- Reports without enough detail to reproduce or assess impact
